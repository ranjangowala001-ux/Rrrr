# Athenian Salon & Academy

Premium luxury salon and academy website prototype built as a responsive single-page experience.

## Included
- Luxury 3D-inspired/parallax hero and glassmorphism UI
- Services and offer catalogue using the supplied pricing
- Booking flow with unique booking IDs
- Branch directory and supplied Guwahati contact details
- Review submission UI with moderation placeholder
- Gallery/lightbox
- Admin dashboard UI for bookings/settings/export
- Responsive mobile/tablet/desktop layout
- SEO metadata and conversion-focused CTAs

## Production integrations still required
Configure server-side Supabase/PostgreSQL, secure admin authentication, Razorpay, WhatsApp Business API, email provider, Google Maps, and real uploaded salon media. Secrets must be environment variables and must never be committed to this repository.

The frontend deliberately does not invent customer reviews, awards, customer counts, branch addresses, or payment credentials.
